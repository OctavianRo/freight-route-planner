How routes are estimated

The planner builds alternatives starting with older, heavier and more distant orders. It tests where each order fits, then tries moving orders within and between trips. It prefers fewer trips. Among plans with the same trip count, it balances total road kilometres against delaying older orders, using your order-age priority setting. Every trip must satisfy both limits, including the depot return.

Distances are driving estimates between postcode district or area centres, including for full postcodes. Use these trips for load planning. Routing uses a car profile. Confirm delivery addresses and HGV access before dispatch. The heuristic can produce a longer route or more loads than the mathematical optimum.
